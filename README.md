# Java DSA Roadmap

This folder contains core Data Structures and Algorithms (DSA) topics implemented in Java.

## Folder Structure

- arrays/       -> Array problems and concepts
- linkedlist/   -> Singly, Doubly, Circular Linked Lists
- sorting/      -> Sorting algorithms (Bubble, Selection, Merge, Quick, etc.)
- searching/    -> Searching algorithms (Linear, Binary, etc.)

## How to Use

- Each folder will contain Java programs
- Start with arrays, then move to linked lists
- Practice problems and optimize solutions

Happy Coding 🚀
